# 카테고리 분류 기준

검색 필터의 카테고리는 `src/lib/category_classifier.ts`가 반환하는 표준 키를 사용한다. 출처가 서로 다른 명칭을 쓰더라도 제목, 혜택, 원본 카테고리를 함께 판단해 같은 키로 저장한다.

## 계층과 검색 범위

- 상위 `음식`은 한식·양식·일식·중식·카페·주점·분식·육류/구이·오마카세를 모두 포함한다.
- 건강·의료는 병원·치과·한의원처럼 의료 근거가 있을 때만 `병원/의료`로 분류한다. 사주·타로·작명은 별도 `사주/타로`다.
- 세부 항목은 자신의 키만 조회한다. 예를 들어 `육류/구이`를 고르면 일반 한식 전체가 섞이지 않는다.
- `기타`는 원본에 신뢰할 만한 분류 근거가 없는 경우만 사용한다. 기존 `general` 값도 기타에 포함해 누락을 막는다.

## 우선순위

1. 명시적인 업종 신호(오마카세, 마라탕, 한우, 떡볶이 등)
2. 공고의 제목과 제공 혜택
3. 출처가 제공한 원본 카테고리

`체험`, `체험권` 단독은 분류 근거로 쓰지 않는다. `식사권`은 음식점임을 보이지만, 한·중·일식처럼 세부 요리를 추정하지 않고 `한식/맛집`으로만 분류한다.

## 변경 절차

새 키를 추가할 때는 `category_classifier.ts`, `CATEGORY_GROUP_MAP`, 화면 라벨, 회귀 테스트를 함께 수정한다. 배포 후 `src/scripts/reclassify-active-categories.ts`로 `etc`/`general` 활성 공고만 보강하고, 상위·세부 필터가 각각 의도한 집합만 반환하는지 QA한다. 출처가 준 구체 카테고리는 이 스크립트로 일괄 덮어쓰지 않는다.
