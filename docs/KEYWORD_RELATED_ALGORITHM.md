# 연관검색어 산출 기준

키워드마스터는 검색량이 확인된 연관어만 노출한다. 월간 검색량은 네이버 검색광고 API의 PC와 모바일 값을 합산하며, 비공개 표기나 미집계 값은 제외한다.

## 후보 출처

- **검색광고 연관**: 검색광고 API가 반환한 연관 키워드
- **네이버 자동완성**: 입력어와 보조 질의의 네이버 자동완성 결과
- **주제 확장**: 분류된 상품·지역·브랜드의 제한된 보완 후보
- **문맥 확장**: 지역, 장소, 계절, 브랜드 등의 탐색 의도 보완 후보

각 결과에는 실제로 사용된 출처를 함께 표시한다. 내부 확장 후보도 검색광고 API로 검색량을 재확인하기 전에는 결과에 표시하지 않는다.
한 번의 조회에서는 품질 지표를 계산할 후보를 최대 70개까지 처리한다. 실제 반환 수는 검색광고에서 검색량이 집계되고 관련성 필터를 통과한 수만큼이다.

## 기본 순위

기본 순위는 다음 세 신호를 합산한다.

1. 입력 키워드와의 문자·단어 관련성
2. 후보 출처의 신뢰도(검색광고 연관, 자동완성, 내부 확장 순)
3. 확인된 월간 검색량의 로그 점수

검색량은 보조 신호다. 높은 검색량의 범용어가 입력어와 직접 관련된 키워드를 앞지르지 않도록 로그 스케일을 사용한다. 표에서는 사용자가 월간 검색량, 포스팅 수, 경쟁비율 등으로 다시 정렬할 수 있다.

## 운영 원칙

후보 출처별 클릭·재검색 지표가 충분히 쌓이기 전에는 사용자 행동을 순위에 반영하지 않는다. 결과 품질은 대표 검색어 회귀 테스트로 확인하고, 새 필터나 확장 규칙은 오분류 사례와 함께 추가한다.
