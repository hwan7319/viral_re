## 출처 수집 결과

독립 라이브 어댑터 검사에서 강남맛집, 디너의여왕, 리뷰노트, 클라우드리뷰, 레뷰, 미블, 놀러와체험단, 모블, 아싸뷰, 오마이블로그, 리뷰플레이스는 ID·제목·원본 URL·플랫폼 형식 계약을 통과했다.

- **포블로그**: EC2 IP 기준 `4blog.net` 목록 API가 HTTP 403을 반환했다. 운영 상태도 `EMPTY`다. 데이터가 잘못 파싱된 문제가 아니라 원본의 서버 IP 차단으로 판단한다. 별도 프록시/허용 IP/공식 제휴 경로 검토가 필요하다.
- **링블**: 단독 심층 어댑터 검사는 상세 마감일 보강 때문에 90초 제한을 초과했다. 다만 운영 벌크 수집은 최근 405건 성공 상태다. 기능 중단은 아니지만, 상세 보강을 큐/배치로 분리하거나 페이지 예산을 낮춰 온디맨드 지연을 줄일 필요가 있다.
- **아싸뷰**: 목록에서 확정 마감일을 제공하지 않는 선착순 유형이 있어 목록 기준 마감일은 비어 있다. 임의 날짜를 만들지 않는 현 정책과 일치한다.
