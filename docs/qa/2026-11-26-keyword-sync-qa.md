## 실수집 상태 전이

운영 EC2에서 `삼겹살` 키워드를 한 번 실행했다.

1. 첫 응답은 기존 DB의 101건을 즉시 반환했고 상태는 `queued`였다.
2. 약 2초 후 상태는 `running`으로 전환됐다.
3. 약 41초 뒤 `completed`가 됐고 618건을 수집·병합했다.
4. 읽기 전용 최종 재조회는 217건을 반환했다. 화면은 이 완료 상태를 2초 간격으로 확인한 뒤 같은 방식으로 자동 재조회한다.

포블로그는 EC2 IP에서 원본이 HTTP 403을 반환해 `failedSources: ["포블로그"]`로 보고됐다. 이는 성공처럼 숨기지 않고 기존 저장 데이터를 표시한다. 나머지 12개 출처는 가장 최근 운영 수집 상태에서 성공이다. 포블로그의 원본 차단 해소는 허용 IP 또는 공식 API/제휴 경로가 필요한 별도 운영 과제다.
